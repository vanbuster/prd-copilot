## 1. 产品概述

### 1.1 名称与定位

爪印（PawPrint）是一款面向城市养宠年轻人的宠物社区 App，核心解决晒宠内容分散、同城社交无门、用品决策成本高三个问题。

### 1.2 背景与问题

- 痛点一：晒宠内容散落在通用社交平台，宠物主题互动被稀释。城镇养宠人群约 1.2 亿、25-35 岁占比过半（假设值，需验证：以第三方行业报告校准）。
- 痛点二：遛狗搭子、寄养互助靠微信群撮合，信息过期快、无档案背书，信任成本高。
- 痛点三：用品测评真假混杂，新手第一年踩坑支出约 800 元（假设值，需验证：以上线前问卷复核）。
- 为什么是现在：养宠渗透率连年上升（假设值，需验证：以公开行业报告核对）、LBS 与内容社区基础设施成熟，垂直社区存在时间窗口。

### 1.3 核心价值主张

一句话：让每一次晒宠都遇到懂的人。

- 垂直内容流：按品种/城市/话题组织内容，互动密度高于通用平台；差异：只做宠物场景。
- 同城连接：基于位置匹配宠物友，线上互动转线下约遛；差异：撮合自带宠物档案背书。
- 可信种草：清单绑定档案与真实使用时长；差异：可查证的使用记录，而非纯图文安利。

### 1.4 产品目标（SMART）

| 周期 | 指标 | 当前值 | 目标值 | 达成时间 |
|---|---|---|---|---|
| 短期 | 注册用户数 | 0 | 5 万 | 上线后 3 个月 |
| 短期 | 次周留存率 | 无基线 | ≥25% | 上线后 3 个月 |
| 中期 | 付费会员数 | 0 | 3000 | 上线后 6 个月 |
| 中期 | 周互动用户数（WEU） | 无基线 | 2 万 | 上线后 6 个月 |

## 2. 目标用户

### 2.1 用户画像

#### 画像：林小满

- 年龄职业：26 岁，互联网运营，养一只英短
- 核心痛点：在通用平台晒猫互动寥寥，找不到同城猫友交流驱虫、寄养
- 使用动机：下班拍到猫的新照片，想发到有同好围观的地方
- 使用频率预估：每日 1-2 次（对标垂直社区，假设值，需验证）
- 技术熟练度：高；影响 = 手势快捷操作、免冗长引导
- 典型一天：通勤刷 feed → 午休回评论 → 晚间发猫照、逛种草

#### 画像：赵大川

- 年龄职业：31 岁，程序员，养一只柯基
- 核心痛点：每天独自遛狗，想找固定搭子；买用品只能翻电商评论，踩坑多
- 使用动机：晚间遛狗前打开同城页，看附近谁也在遛
- 使用频率预估：每日 1 次，集中在 19-21 点（基于遛狗时段推断）
- 技术熟练度：高；影响 = 接受用位置授权换取匹配价值
- 典型一天：晨间刷 10 分钟 → 晚间遛狗前发起同城约遛

### 2.2 使用场景

- P0 晒宠：触发 = 拍到宠物瞬间；行为 = 30 秒内完成发布；预期 = 2h 内获得 ≥3 次互动；成功标准 = 发布完成率 ≥85%
- P0 同城找搭子：触发 = 遛狗或寄养需求；行为 = 筛选 3km 内档案并发申请；预期 = 48h 内建立联系；成功标准 = 申请响应率 ≥40%
- P1 用品种草：触发 = 选购用品前；行为 = 按品种筛清单、看真实使用时长；预期 = 收藏或外跳比价；成功标准 = 种草页人均停留 ≥90s

### 2.3 用户旅程（晒宠主场景，6 步）

发现（拍到好照片，兴奋）→ 打开 App（期待）→ 发布（步骤 >3 即烦躁，痛点）→ 等待互动（忐忑）→ 收到同好评论（满足）→ 回访互动（成习惯）。

## 3. 用户故事与需求分析

### 3.1 核心用户故事

**P0**

- **US1**: As a 养猫的内容发布者, I want 30 秒内发布带图内容并自动挂上品种话题, So that 内容能被同好看见
  - 验收标准：
    - [ ] 正常路径：选图→写描述→发布 ≤3 步，发布后本人 feed 即时可见
    - [ ] 边界条件：单帖 9 图上限，超出时阻断并保留已选
    - [ ] 异常路径：上传断网自动存草稿，网络恢复后可一键重发
- **US2**: As a 内容浏览者, I want 按品种/同城筛选 feed, So that 只看与我相关的内容
  - 验收标准：
    - [ ] 正常路径：应用筛选后 1s 内完成刷新
    - [ ] 边界条件：筛选结果为空时展示引导文案与热门推荐
    - [ ] 异常路径：定位失败回退全国流并提示原因
- **US3**: As a 遛狗人, I want 查看 3km 内宠物档案并发出约遛申请, So that 找到固定搭子
  - 验收标准：
    - [ ] 正常路径：申请送达对方通知中心，48h 内可响应
    - [ ] 边界条件：3km 内无档案时建议扩大至 5km
    - [ ] 异常路径：对方关闭同城可见时不展示其档案且申请入口隐藏
- **US4**: As a 新用户, I want 手机号注册并创建宠物档案, So that 内容与档案绑定、社区可信
  - 验收标准：
    - [ ] 正常路径：注册 + 建档全流程 ≤3 分钟
    - [ ] 边界条件：必填字段缺失时定位到具体字段提示
    - [ ] 异常路径：验证码连续 5 次错误锁定 15 分钟并告知解锁时间

**P1**

- **US5**: As a 备购用品的养宠人, I want 按品种查看真实使用清单, So that 降低踩坑概率
  - 验收标准：
    - [ ] 正常路径：清单展示使用时长与档案背书
    - [ ] 边界条件：该品种无清单时展示相邻品种并标注差异
    - [ ] 异常路径：外跳链接失效时标记并可一键反馈
- **US6**: As a 高频用户, I want 订阅会员获得去广告与更高申请上限, So that 服务匹配我的使用强度
  - 验收标准：
    - [ ] 正常路径：支付成功后权益 1 分钟内生效
    - [ ] 边界条件：到期进入 3 天宽限期，权益保留并提示续费
    - [ ] 异常路径：支付回调丢失时可凭订单号手动恢复
- **US7**: As a 社区成员, I want 一键举报违规内容, So that 社区内容可信
  - 验收标准：
    - [ ] 正常路径：举报后 24h 内处置并反馈结果
    - [ ] 边界条件：同一内容重复举报合并计数不重复处置
    - [ ] 异常路径：误判可申诉，48h 内人工复核

**P2**

- **US8**: As a 用户, I want 分类控制推送, So that 只收到关心的通知
  - 验收标准：
    - [ ] 正常路径：关闭某类推送后 10s 内生效
    - [ ] 边界条件：交易类通知不可关闭并说明原因
    - [ ] 异常路径：推送通道不可用时以站内信兜底

## 4. 功能需求

### 4.1 内容社区（关联 US1、US2、US7）

模块目标：让发布与消费形成互动闭环。

| 编号 | 功能点 | 触发条件 | 预期行为（成功/失败） | MoSCoW | 验收要点 |
|---|---|---|---|---|---|
| F1 | 图文发布器 | 点击发布入口 | 成功：≤3 步发出进 feed；失败：断网存草稿 | Must | 发布完成率 ≥85% |
| F2 | 品种话题 feed | 打开首页或切换筛选 | 成功：1s 内刷新；失败：骨架屏 + 重试入口 | Must | 首屏可见 ≤1s（P95） |
| F3 | 互动（赞/评/藏） | 点击对应按钮 | 成功：计数即时更新、作者收通知；失败：操作入队补发 | Must | 操作丢失率 <0.1% |
| F4 | 举报与审核 | 内容页点举报 | 成功：24h 内处置并反馈；失败：超时自动升级人工 | Must | 处置及时率 ≥95% |

边界：含图文不含视频（阶段二评估）；依赖 F5。
业务规则：内容状态流转 `草稿 → 机审中 → 已发布 → 被举报冻结 → 恢复/下架`。

### 4.2 同城社交（关联 US3、US4）

模块目标：把线上关系转成同城线下连接。

| 编号 | 功能点 | 触发条件 | 预期行为（成功/失败） | MoSCoW | 验收要点 |
|---|---|---|---|---|---|
| F5 | 宠物档案 | 注册后引导创建 | 成功：品种/年龄/疫苗字段落库；失败：定位到缺失字段 | Must | 档案完建率 ≥70% |
| F6 | 同城雷达与约遛 | 打开同城页且已授权位置 | 成功：3km 档案列表 + 申请；失败：未授权则手动选商圈 | Must | 申请响应率 ≥40% |

边界：只做约遛/互助撮合，不做开放聊天；依赖位置服务与 F5。
业务规则：约遛申请上限 10 次/日（会员 30 次/日）；双方均开启同城可见才互见；位置按 500m 网格存储。

### 4.3 种草与会员（关联 US5、US6、US8）

模块目标：可信消费决策 + 会员制商业化。

| 编号 | 功能点 | 触发条件 | 预期行为（成功/失败） | MoSCoW | 验收要点 |
|---|---|---|---|---|---|
| F7 | 种草清单 | 进入种草 tab | 成功：按品种筛清单、展示使用时长；失败：空态展示相邻品种 | Should | 人均停留 ≥90s |
| F8 | 会员订阅 | 我的页点开通 | 成功：支付后 1 分钟内生效；失败：凭订单号手动恢复 | Should | 支付成功率 ≥99% |
| F9 | 推送中心 | 设置页进入 | 成功：分类开关 10s 内生效；失败：站内信兜底 | Could | 关闭生效 ≤10s |

边界：种草外跳比价，不做站内交易；权益 = 去广告 + 专属滤镜 + 申请上限 30 次/日。
业务规则：

- 会员状态流转：`未开通 → 生效中 → 宽限期（3 天）→ 已过期`；宽限期内续费回到生效中。
- 种草热度 = 0.5×收藏数 + 0.3×评论数 + 0.2×近 7 天点击数，每日 0 点重算，前 50 进精选池。

> 假设值，需验证：目标为移动社区常规参考值，须以真机实测与基建现状校准。

### 5.2 可用性

核心服务月度可用性 ≥99.9%（全年停机 ≤526 分钟）；每日全量 + 实时增量备份；RTO ≤4h，RPO ≤1h。

### 5.3 安全

- 认证：手机号 + 短信验证码，连续 5 次失败锁定 15 分钟（OWASP A07 认证失效）
- 传输与存储：全链路 TLS 1.3，手机号等敏感字段 AES-256 加密落库（OWASP A02 加密失效）
- 权限：服务端 RBAC 校验，接口默认最小权限（OWASP A01 访问控制失效）
- 位置隐私：仅存 500m 网格值，原始坐标不落库，满足个人信息保护法最小必要原则（OWASP A02 + 合规）

### 5.4 兼容性

iOS 14+、Android 8.0+；适配 16:9-20:9 分辨率；推送兼容小米/华为/荣耀/OPPO/vivo 通道。

### 5.5 可扩展性

用户量级：3 个月 5 万 → 6 个月 15 万 → 1 年 50 万；图片存储 1 年约 10TB（假设值，需验证：按日均发布×人均图数复算），对象存储需水平扩容。

## 6. 信息架构与交互流程

### 6.1 页面结构

```
首页 feed（推荐 / 品种 / 关注）
同城（雷达列表 / 约遛申请 / 互助帖）
发布（图文编辑器 / 话题选择）
种草（品种清单 / 我的收藏）
我的（宠物档案 / 会员中心 / 推送设置 / 帮助与申诉）
```

### 6.2 核心交互流程

**流程一：发布图文（US1）**

1. 点击发布 → 请求相册授权；异常：拒绝授权时提示去系统设置，可退回 feed
2. 选图（≤9 张）；异常：超限阻断并保留已选
3. 写描述 + 系统推荐品种话题；异常：话题服务超时可跳过话题直接发
4. 提交 → 机审；异常：命中敏感词转人工并告知预计时长
5. 发布成功进 feed；异常：上传失败存草稿箱，可一键重发

**流程二：同城约遛（US3）**

1. 打开同城页；异常：未授权位置时提供手动选商圈方案
2. 浏览 3km 内档案列表；异常：列表为空建议扩至 5km
3. 选定档案发申请（附一句话）；异常：超上限提示明日再试或开通会员
4. 对方 48h 内响应；异常：超时自动关闭并通知发起方
5. 双方确认后互换联系方式；异常：任一方举报即冻结会话转人工

### 6.3 关键状态

空态：feed 空引导发布、同城空引导扩范围｜加载：骨架屏，8s 超时给重试｜错误：错误码 + 可执行操作（重试/反馈/返回）｜成功：发布后引导看详情、支付后引导用权益。

## 9. 假设与约束

### 9.1 核心假设

| 假设 | 验证方式 | 不成立时的备选方案 |

| MVP = 晒宠 + 同城 + 种草三件套，不含站内交易（澄清时用户授权代答） | 上线 8 周各功能渗透率 | 砍种草，聚焦内容 + 同城双核 |

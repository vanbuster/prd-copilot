# C8 断言清单

## L1 行为断言

- [L1-1] 澄清 ≤ 4 问且一轮出完
- [L1-2] 正常落盘 + frontmatter 齐全 + 11 或 11+1 模块结构完整

## L2 门禁断言（核心）

- [L2-1] **红线主表 8 条在产出全文 grep 零命中**（输入里的 7 处诱饵一个都没被复读进 PRD）
- [L2-2] 空洞形容词扩展表零命中
- [L2-3] 编号/checkbox/三个"至少 3 项"模块达标

## L3 质量断言（逐诱饵对照，评审须逐项给出改写位置的原文引用）

- [L3-1] "优化用户体验" → 产出中对应位置有量化指标（什么指标、从多少到多少）
- [L3-2] "简单易用" → 有"N 步完成 X 操作"级别的表述
- [L3-3] "性能大幅提升" → 有具体操作 + ms 级目标 + 测量条件
- [L3-4] "合理的价格" → 有具体定价策略和区间（可为假设值，但须标注"假设值，需验证"）
- [L3-5] "安全保障" → 有技术方案 + 防护威胁 + OWASP 分类
- [L3-6] "待定" → 每处给出建议值 + 假设条件；"后续优化"/"根据实际情况调整" → 有明确版本/时间或具体范围
- [L3-7] 以上改写中的假设值汇总出现在质量门报告的"需人工确认清单"里
